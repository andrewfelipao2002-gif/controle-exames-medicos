# Controle de Exames Médicos

Front-end de um sistema de controle de exames médicos, com agendamento de exames laboratoriais e de imagem e acompanhamento de status.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades planejadas

- Cadastro de pacientes
- Cadastro de requisição de exame
- Agendamento, remarcação e cancelamento
- Check-in e confirmação de presença
- Acompanhamento de status do exame
- Consulta de laudos e resultados
- Busca e filtros de agendamentos e exames

## Como rodar

1. Clone o repositório:

```
   git clone https://github.com/andrewfelipao2002-gif/controle-exames-medicos.git
```
2. Abra a pasta no VS Code.
3. Abra o `index.html` no navegador (ou use a extensão Live Server).
